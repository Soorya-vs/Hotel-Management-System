# Hotel Management System

A Java Swing and MySQL based Hotel Management System developed to manage hotel operations efficiently through a desktop application interface.

## Features

- Admin Login System
- Employee Management
- Room Management
- Customer Check-In and Check-Out
- Department Details
- Driver Management
- Room Search and Availability
- Database Connectivity using JDBC

## Technologies Used

- Java
- Java Swing
- MySQL
- JDBC
- NetBeans IDE

## Database

The project uses MySQL database connectivity through JDBC.

Database tables include:
- login
- employee
- customer
- room
- department
- driver

## How to Run

1. Install Java JDK and NetBeans.
2. Install MySQL Server.
3. Create the database using the provided SQL file.
4. Add required JAR files:
   - mysql-connector-j
   - rs2xml.jar
5. Open the project in NetBeans.
6. Run `Login.java`.

## Project Structure

- `Login.java` – Login page
- `Dashboard.java` – Main dashboard
- `Conn.java` – Database connection
- `AddEmployee.java` – Employee management
- `AddRooms.java` – Room management
- `CustomerInfo.java` – Customer details
